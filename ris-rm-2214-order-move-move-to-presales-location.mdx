## Overview

The **RIS-RM-2214 – Order Move (Move to Presales Location)** macro intelligently routes orders to the correct warehouse based on stock availability across multiple locations.

<Callout kind="tip" collapsed="false">
  Ensure all warehouse locations are correctly configured and passed in parameters before running this macro.
</Callout>

## Purpose

This macro:

- Checks stock availability across multiple warehouses

- Determines the best fulfillment location

- Moves orders to the appropriate warehouse

- Handles out-of-stock scenarios efficiently

👉 In short:\
Check stock → decide location → move order if needed.

## When It Runs

Typically executed:

- After order import

- Before picking and packing

- During stock validation

- In multi-warehouse environments

- To handle out-of-stock situations

- Manually or via automation workflows

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">
  List of order IDs to process.
</ParamField>

<ParamField path="CheckLocation01" param-type="string" required="true" deprecated="false">
  Default warehouse location.
</ParamField>

<ParamField path="CheckLocation02" param-type="string" required="true" deprecated="false">
  Secondary (backup) warehouse location.
</ParamField>

<ParamField path="CheckLocation03" param-type="string" required="true" deprecated="false">
  PreSales warehouse location.
</ParamField>

<Callout kind="info" collapsed="false">
  All location parameters and OrderIds must be provided for proper execution.
</Callout>

## Simple Explanation

The macro checks stock across multiple warehouses and ensures each order is assigned to the most suitable location where stock is available.
