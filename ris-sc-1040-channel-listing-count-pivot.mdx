## Overview

The **RIS-SC-1040 – Channel Listing Count Pivot** script helps analysts understand marketplace coverage by showing how widely SKUs are listed across different sales channels.

<Callout kind="tip" collapsed="false">
  In simple terms:\
  See which products are listed on which marketplaces and how many times, in a clear pivot/matrix view.
</Callout>

---

## Purpose

This script:

- Identifies all active SKUs

- Checks which sales channels each SKU is listed on

- Counts the number of listings per channel

- Converts the results into a dynamic pivot table where each channel becomes a column

---

## When It Runs

Used for catalog audits, marketplace analysis, and listing management.

**Typically runs:**

- Manually executed by analysts

- During listing audits

- For marketplace coverage analysis

- While identifying missing listings

- For catalog expansion planning

---

## Parameters

<ParamField path="cols" param-type="string" required="true" deprecated="false">
  Dynamic column list for pivot table; stores the generated channel columns.
</ParamField>

<ParamField path="query" param-type="string" required="true" deprecated="false">
  Holds the dynamic SQL query for pivot execution.
</ParamField>

<Callout kind="info" collapsed="false">
  These parameters allow dynamic generation of pivot columns and execution of the query without manually updating channel names.
</Callout>

---

## Simple Explanation

The script takes all active SKUs, counts their listings per sales channel, and converts rows into columns so that each channel becomes a pivot column.

---

## Step-by-Step Process

<Steps>
  <Step title="Generate Channel List" icon="list" title-type="p">
    Collect all distinct channel names from Stock\_ChannelSKU for pivot columns.
  </Step>

  <Step title="Create Dynamic Columns" icon="code" title-type="p">
    Build the column string dynamically and assign to the cols parameter.
  </Step>

  <Step title="Prepare Base Data" icon="database" title-type="p">
    Combine SKU and channel information to form the dataset for pivoting.
  </Step>

  <Step title="Apply Pivot Logic" icon="grid" title-type="p">
    Use the query parameter to count listings per channel and convert rows into pivot columns.
  </Step>

  <Step title="Execute Query" icon="play" title-type="p">
    Run the dynamic SQL stored in query to generate the final report.
  </Step>
</Steps>
