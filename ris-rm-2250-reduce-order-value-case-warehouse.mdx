## Overview

The **RIS-RM-2250 – Reduce Order Value – Case Warehouse** macro applies controlled percentage-based discounts to orders while ensuring all financial values and item-level data are updated accurately.

<Callout kind="tip" collapsed="false">
  This macro includes safety checks to prevent duplicate processing and ensure audit traceability.
</Callout>

## Purpose

This macro:

- Reduces order value by a given percentage

- Updates item-level pricing and totals

- Removes shipping protection (if present)

- Maintains a full audit trail

👉 In short:\
Validate → remove extras → apply discount → update totals → log changes.

## When It Runs

Typically executed:

- During warehouse-specific pricing adjustments

- Bulk discount application

- Order correction workflows

- Regional pricing adjustments

- Financial updates or promotions

- Manually or via automation

## Parameters

<ParamField path="OrderIds" param-type="GUID[]" required="true" deprecated="false">
  List of orders to process.
</ParamField>

<ParamField path="Percentage" param-type="double" required="true" deprecated="false">
  Percentage value to reduce the order total.
</ParamField>

<Callout kind="info" collapsed="false">
  Example: Percentage = 10 → Reduces each order value by 10%.
</Callout>

## Simple Explanation

The macro processes each order, removes extra charges, applies a percentage discount across all values, updates items and totals, and records both original and updated data for audit purposes.
