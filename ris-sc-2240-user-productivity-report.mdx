## Overview

The **RIS-SC-2240 – User Productivity Report&#x20;**&#x20;provides a detailed analysis of warehouse picking performance by evaluating user efficiency, speed, and output.

<Callout kind="tip" collapsed="false">
  Use date filters to focus on specific periods for more accurate performance analysis.
</Callout>

## Purpose

This report:

- Tracks picking activity per user

- Measures efficiency and completion rates

- Calculates time-based performance metrics

- Provides insights into productivity

👉 In short:\
Track picking work → measure time → calculate efficiency → analyze performance.

## When It Runs

Typically executed:

- Daily or weekly productivity reviews

- Staff performance analysis

- Warehouse management reporting

- Team efficiency monitoring

- Training and improvement evaluation

- Manually or via scheduled reports
