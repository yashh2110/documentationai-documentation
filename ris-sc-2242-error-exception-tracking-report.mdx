## Overview

The **RIS-SC-2242 – Error & Exception Tracking Report** provides insights into picking accuracy by tracking errors and exceptions across warehouse operations.

<Callout kind="tip" collapsed="false">
  Use this report alongside productivity reports to balance speed and accuracy analysis.
</Callout>

## Purpose

This report:

- Tracks errors and exceptions in picking

- Measures accuracy per user

- Calculates error rates

- Supports quality control and improvement

👉 In short:\
Track errors → calculate rates → measure accuracy → improve quality.

## When It Runs

Typically executed:

- Daily warehouse quality checks

- Weekly performance reviews

- Error and exception analysis

- Staff training evaluation

- Process improvement initiatives

- Manually or via scheduled reports
