## Overview

The **RIS-RM-2311 – ShipStation Order Splitter** macro intelligently splits orders using two key logics:

- **“Ships Alone” items**

- **Maximum weight per order**

It ensures proper shipment grouping and prepares orders for seamless processing in ShipStation.

<Callout kind="tip" collapsed="false">
  Ensure required rules and extended properties are properly configured before running this macro.
</Callout>

---

## Purpose

This macro:

- Splits items that must ship alone

- Groups remaining items based on weight limits

- Flags overweight items for manual handling

- Triggers rules for ShipStation processing

👉 In short:\
Split orders intelligently based on shipping rules and weight limits.

---

Used for shipping preparation and automation

Typically runs:

- Manually triggered

- As part of automation workflows

- Before sending orders to ShipStation

## Parameters

## How It Works

<Steps>
  <Step title="Validate Rules" icon="shield-check" title-type="p">
    Ensure required automation rules exist. Stop execution if missing.
  </Step>

  <Step title="Validate Orders" icon="check-square" title-type="p">
    Skip invalid or already processed orders.
  </Step>

  <Step title="Pre-Processing Rule" icon="play-circle" title-type="p">
    Run rule to prepare dispatch and shipping data.
  </Step>

  <Step title="Classify Items" icon="layers" title-type="p">
    Categorize items into:

    - Ships Alone items

    - Overweight items

    - Normal items
  </Step>

  <Step title="Ships Alone Splitting" icon="user-minus" title-type="p">
    Split each Ships Alone item into individual orders.
    If only such items exist, keep one in the parent order.
  </Step>

  <Step title="Weight-Based Grouping" icon="package" title-type="p">
    Group normal items using max weight limit with greedy logic.
  </Step>

  <Step title="Handle Overweight Items" icon="alert-triangle" title-type="p">
    Items exceeding max weight are not split and flagged for manual review.
  </Step>

  <Step title="Create Child Orders" icon="copy" title-type="p">
    Generate new orders using SplitOrder API while preserving customer and shipping details.
  </Step>

  <Step title="Add Notes & Logs" icon="file-text" title-type="p">
    Record split summary, overweight warnings, and parent-child relationships.
  </Step>

  <Step title="Assign Identifier & Run Rules" icon="tag" title-type="p">
    Assign identifiers and trigger rules engine for ShipStation integration.
  </Step>

  <Step title="Mark as Processed" icon="check-circle" title-type="p">
    Add Extended Property ShipStationOrderSplitter = Yes to prevent reprocessing.
  </Step>
</Steps>

## Example Scenario

<Expandable title="Mixed Order Splitting Example" default-open="false">
  Order contains:

  - SKU A → Ships Alone (Qty: 2)

  - SKU B → Weight 3 lbs (Qty: 3)

  - Max Weight = 5 lbs

  👉 The macro:

  - Splits Ships Alone items individually

  - Groups remaining items within weight limit

  - Flags any overweight cases

  Result:

  - Order 1 (Parent): SKU A (1)

  - Order 2: SKU A (1)

  - Order 3: SKU B (within 5 lbs limit)

  - Order 4: Remaining SKU B
