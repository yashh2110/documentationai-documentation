## Overview

The **RIS-SC-2245 – SLAs & KPI Compliance Report** tracks whether warehouse operations are completed within defined SLA limits and provides insights into performance and delays.

<Callout kind="tip" collapsed="false">
  Define realistic SLA values to ensure meaningful performance evaluation.
</Callout>

## Purpose

This report:

- Compares actual work time against SLA limits

- Identifies on-time and delayed operations

- Calculates SLA compliance percentage

- Tracks overall performance metrics

👉 In short:\
Set SLA → measure time → compare → track performance.

## When It Runs

Typically executed:

- Daily performance tracking

- SLA compliance checks

- Warehouse performance reviews

- Client reporting

- Delay and issue analysis

- Manually or via scheduled reports

## Data Used

- Pickwave start and end time

- Time taken (duration in minutes)

- Orders within each pickwave

- Items picked

- User handling the work

## Simple Explanation

The report measures how long tasks take and compares them with predefined SLA limits to determine whether work is completed on time or delayed.
