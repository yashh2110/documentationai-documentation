## Overview

The **RIS-RM-2222 – Amazon Customisation Data Extract & Add to Order Notes** macro extracts customization details from Amazon order XML and converts them into readable order notes for warehouse and processing teams.

<Callout kind="tip" collapsed="false">
  Ensure correct XML node paths are provided to accurately extract customization data.
</Callout>

## Purpose

This macro:

- Reads customization data from Amazon XML

- Extracts personalization details (text, options, etc.)

- Formats the extracted data

- Adds it to order notes

- Prevents duplicate note creation

👉 In short:\
Read XML → extract customization → format → add as order notes.

## When It Runs

Typically executed:

- After Amazon order import

- Before picking and packing

- For personalized/custom product handling

- During printing/customization workflows

- When orders include names, text, or design options

- Manually or via automation workflows

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">
  List of order IDs to process.
</ParamField>

<ParamField path="xmlnodelist" param-type="string" required="true" deprecated="false">
  XML node paths used to extract customization data.
</ParamField>

<Callout kind="info" collapsed="false">
  Both OrderIds and xmlnodelist must be provided for proper execution.
</Callout>

The macro reads Amazon XML, finds customization details via a URL, extracts relevant values, and saves them as formatted notes in the order.
