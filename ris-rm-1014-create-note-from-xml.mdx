## Overview

The **RIS-RM-1014 – Create Note From XML** macro extracts the buyer’s name from an order’s XML data and stores it as a visible order note.

This helps convert structured XML information into easily accessible data within the order interface.

<Callout kind="tip" collapsed="false">
  Ensure the XML structure contains the required node (ChannelBuyerName) before running this macro.
</Callout>

## Purpose

This macro:

- Retrieves XML data from an order  
- Extracts the buyer’s name  
- Creates a visible order note  
- Enhances order data visibility  

👉 In short:  
Extract buyer name from XML and store it as an order note.

## When It Runs

Used for order data enrichment and visibility

Typically runs:

- Manually triggered (per order)  
- During order processing  
- During data enrichment workflows

## How It Works

<Steps>
  <Step title="Fetch XML Data" icon="download" title-type="p">
    Retrieve XML data for the specified order.
  </Step>

  <Step title="Parse XML" icon="code" title-type="p">
    Convert XML into structured format using XElement.
  </Step>

  <Step title="Locate Node" icon="search" title-type="p">
    Navigate to: Order → ChannelBuyerName.
  </Step>

  <Step title="Extract Buyer Name" icon="user" title-type="p">
    Read the buyer’s name from the XML node.
  </Step>

  <Step title="Create Note" icon="edit" title-type="p">
    Create a new order note with the extracted value.
  </Step>

  <Step title="Set Visibility" icon="eye" title-type="p">
    Mark the note as non-internal (visible).
  </Step>

  <Step title="Save & Log" icon="file-text" title-type="p">
    Save the note and log execution details including errors.
  </Step>
</Steps>

## Important Notes

<Callout kind="warning" collapsed="false">
  - Works only if XML contains ChannelBuyerName node  
  - May overwrite existing notes instead of appending  
  - Processes one order per execution

</Callout>
