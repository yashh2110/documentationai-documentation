## Overview

Manufacturing Sheet 2 is a custom feature available in the Orders screen.

It generates a detailed and printable manufacturing sheet that includes product description, accessories, and instruction details required during production.

This sheet is mainly used by the production and assembly team.

## Purpose

The purpose of this feature is to provide complete manufacturing information in one place.

It helps teams avoid manual checks and ensures all required product details, accessories, and instructions are clearly available before production starts.

## Key Features

- Works on selected orders in Linnworks

- Groups products by SKU

- Combines quantities for the same product

- Retrieves extended product details

- Displays product description and accessories

- Includes customer postcode

- Generates a printable manufacturing sheet

- Opens print screen automatically

## Data Required

The system uses product extended properties.

ProductImage\
Product image

Height\
Product height

Width\
Product width

Description\
Product description

RoofandFloor\
Roof and floor details

SticksRequired\
Number of sticks required

AccessoriesPackReference\
Accessories pack reference

InstructionsManualReferenceLetter\
Instruction reference

## Output Fields

The manufacturing sheet includes

- Serial Number

- Product Image

- Height

- Width

- Description

- Postcode

- Roof and Floor

- Sticks Required

- Accessories Pack Reference

- Instructions Manual Reference Letter

## How It Works

Step 1\
User selects one or more orders from the Orders screen

Step 2\
User clicks Manufacturing Sheet 2 button

Step 3\
System collects all order items and customer details

Step 4\
Items are grouped by SKU and quantities are combined

Step 5\
System retrieves product details and extended properties

Step 6\
Manufacturing sheet is generated

Step 7\
Print screen opens automatically

## Important Notes

- At least one order must be selected

- Orders without items will not be included

- Product details depend on available system data

- Images will be shown only if available

## Error Handling

If no order is selected\
System shows message Please select at least one order

If selected orders have no items\
System shows message No orders received for Manufacturing Sheet 2

If any issue occurs\
System shows message Error generating Manufacturing Sheet 2

## Business Benefits

- Provides complete manufacturing information

- Reduces manual work

- Improves production accuracy

- Helps teams prepare accessories and materials

- Improves coordination between teams

## Summary

Manufacturing Sheet 2 is an enhanced version of the manufacturing document.

It provides additional details such as description, accessories, and instructions, helping the production team work more efficiently and accurately.
