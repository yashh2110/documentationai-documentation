## Overview

The **RIS-SC-2272 – Detailed Stock Movement Data** report tracks internal stock transfers between bin locations.

It reconstructs movement activity by pairing stock-out and stock-in transactions, giving a clear view of bin-to-bin transfers along with financial impact.

<Callout kind="tip" collapsed="false">
  This report matches outbound and inbound movements using quantity, timestamp, and user to accurately reconstruct stock transfers.
</Callout>

---

## Purpose

This report:

- Tracks stock movement between bin locations

- Identifies source and destination bins

- Captures user activity for each movement

- Calculates value impact of stock transfers

👉 In short:\
Track who moved stock, from where, to where, and what value was affected.

---

Executed on-demand (SQL report)

## How It Works

<Steps>
  <Step title="Capture Outbound Movements" icon="arrow-up-right" title-type="p">
    Retrieves stock movements where quantity is negative (stock leaving a bin).
  </Step>

  <Step title="Capture Inbound Movements" icon="arrow-down-left" title-type="p">
    Retrieves stock movements where quantity is positive (stock entering a bin).
  </Step>

  <Step title="Filter Movement Type" icon="filter" title-type="p">
    Includes only records where:

    - ChangeNote = "Stock Moved"
  </Step>

  <Step title="Match Movement Pairs" icon="link" title-type="p">
    Matches outbound and inbound records using:

    - Same user

    - Same timestamp

    - Opposite quantities
  </Step>

  <Step title="Combine Data" icon="layers" title-type="p">
    Builds a unified dataset showing:

    - From Bin

    - To Bin

    - Quantity moved

    - Value change
  </Step>

  <Step title="Join Inventory Data" icon="database" title-type="p">
    Links movement data with:

    - Batch inventory

    - Batch records

    - Stock item details
  </Step>

  <Step title="Fetch Current Bin" icon="map-pin" title-type="p">
    Retrieves current bin location from inventory for reference.
  </Step>

  <Step title="Prepare Final Output" icon="file-text" title-type="p">
    Formats results with SKU, quantity, value, user, and bin details.
  </Step>

  <Step title="Sort Results" icon="arrow-down" title-type="p">
    Orders data by movement date (latest first).
  </Step>
</Steps>

## Important Notes

<Callout kind="warning" collapsed="false">
  - Only movements with "Stock Moved" note are included

  - Matching is based on timestamp and user, so precision is critical

  - Movements must have equal and opposite quantities to match

  - If matching fails, some movements may not appear

  - Current bin may differ from original source bin

  - Value is based on StockValueDelta

  - Date filter includes entire end date using DATEADD logic
</Callout>
