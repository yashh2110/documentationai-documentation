## Overview

The **RIS-RM-1007 – Dropship Macro** automates the handling of dropship orders by identifying supplier-based items, splitting orders when required, and sending order details directly to suppliers via email.

It ensures efficient supplier communication and streamlined dropshipping workflows.

<Callout kind="tip" collapsed="false">
  Ensure supplier names follow the ds- naming convention and have valid email addresses configured.
</Callout>

## Purpose

This macro:

- Identifies dropship items within orders

- Splits orders based on suppliers

- Sends order details to suppliers via email

👉 In short:\
Automate dropship processing and supplier communication.

## When It Runs

Used for dropshipping automation & supplier communication

Typically runs:

- Scheduled execution (automated processing)

- Manually for selected orders

## How It Works

<Steps>
  <Step title="Fetch Orders" icon="download" title-type="p">
    Retrieve orders and skip already processed ones.
  </Step>

  <Step title="Identify Dropship Items" icon="search" title-type="p">
    Detect items where supplier name contains ds-.
  </Step>

  <Step title="Separate Items" icon="layers" title-type="p">
    Split dropship and non-dropship items.
  </Step>

  <Step title="Group by Supplier" icon="users" title-type="p">
    Organize dropship items based on supplier details.
  </Step>

  <Step title="Evaluate Split Logic" icon="git-branch" title-type="p">
    ✔ Only dropship items → process directly\
    ✔ Mixed/multi-supplier → split order
  </Step>

  <Step title="Split Orders" icon="copy" title-type="p">
    Create separate orders for each supplier if required.
  </Step>

  <Step title="Send Emails" icon="mail" title-type="p">
    Send order details to suppliers including items, pricing, and delivery info.
  </Step>

  <Step title="Track Results" icon="check-circle" title-type="p">
    Log success, failures, and missing emails.
  </Step>

  <Step title="Update Orders" icon="save" title-type="p">
    Add notes and assign orders to appropriate folders.
  </Step>
</Steps>

<Callout kind="warning" collapsed="false">
