## Overview

The **RIS-RM-2281 – Shopify Customisation to Notes** macro enhances order visibility by extracting personalization data from Shopify XML and converting it into structured, readable notes.

<Callout kind="tip" collapsed="false">
  Use this macro for Shopify orders with personalization to ensure warehouse teams can easily access customization details.
</Callout>

## Purpose

This macro:

- Extracts customization data from Shopify XML

- Filters out unnecessary/system fields

- Formats data into structured notes

- Saves notes in the order

- Prevents duplicate note creation

👉 In short:\
Read XML → extract customization → format → save notes.

## When It Runs

Typically executed:

- After Shopify order import

- Before picking and packing

- When personalized products exist

- During order processing automation

- When XML-based customization is required

- Manually or via automation

The macro reads Shopify XML data, extracts relevant customization details, formats them into a readable structure, and saves them as order notes while avoiding duplicates.
