## Quick Start

Get up and running with Rishvi services in minutes.

<Steps>
  <Step title="Sign Up" icon="user-plus" title-type="p">
    Create your account at `https://dashboard.example.com` and obtain your API key.
  </Step>

  <Step title="Integrate Linnworks" icon="settings" title-type="p">
    Connect your Linnworks account using the API endpoint.

    <CodeGroup show-lines="true" tabs={[]}>
      ```javascript
      const response = await fetch('https://api.example.com/v1/linnworks/connect', {
        method: 'POST',
        headers: { 'Authorization': `Bearer ${YOUR_API_KEY}` },
        body: JSON.stringify({ accountId: 'your-linnworks-id' })
      });
      const data = await response.json();
      console.log(data);
      ```

      ```python
      import requests
      response = requests.post(
          'https://api.example.com/v1/linnworks/connect',
          headers={'Authorization': f'Bearer {YOUR_API_KEY}'},
          json={'accountId': 'your-linnworks-id'}
      )
      print(response.json())
      ```
