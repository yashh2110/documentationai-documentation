## Overview

The **RIS-RM-2230 – Prime Identifier to Web Order** macro ensures that orders are properly tagged with a specified identifier, such as “Prime Order”, for better visibility and processing.

<Callout kind="tip" collapsed="false">
  Ensure the identifier name is correctly defined to maintain consistency across orders.
</Callout>

## Purpose

This macro:

- Validates input parameters

- Checks if identifier exists

- Creates identifier if missing

- Assigns identifier to orders

👉 In short:\
Check tag → create if needed → assign to orders.

## When It Runs

Typically executed:

- After order import

- During order processing

- For identifying special orders (e.g., Prime orders)

- For filtering and reporting

- As part of automation workflows

- Manually when needed

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">
  List of order IDs to process.
</ParamField>

<ParamField path="PrimeIdentifier" param-type="string" required="true" deprecated="false">
  Name of the identifier/tag to assign.
</ParamField>

<Callout kind="info" collapsed="false">
  Both OrderIds and PrimeIdentifier must be provided for proper execution.
</Callout>

## Simple Explanation

The macro checks if a specific identifier exists, creates it if necessary, and assigns it to all selected orders.
