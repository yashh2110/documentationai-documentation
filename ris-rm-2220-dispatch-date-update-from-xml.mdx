## Overview

The **RIS-RM-2220 – Dispatch Date Update from XML** macro ensures that all orders have a valid dispatch date by extracting it from XML data or applying a default fallback when necessary.

<Callout kind="tip" collapsed="false">
  Ensure the default fallback date is correctly configured to avoid incorrect scheduling.
</Callout>

## Purpose

This macro:

- Reads dispatch date from order XML

- Validates the extracted date

- Updates the order’s Despatch By Date

- Applies a fallback date if needed

- Tags processed orders

👉 In short:\
Read XML date → validate → update dispatch date → fallback if needed.

## When It Runs

Typically executed:

- After order import from Magento

- Before order processing

- Before shipping / dispatch planning

- When dispatch date is received from external systems

- For delivery scheduling and planning

- Manually or via automation workflows

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">
  List of order IDs to process.
</ParamField>

<ParamField path="DefualtDate" param-type="string" required="true" deprecated="false">
  Fallback date used when XML dispatch date is missing or invalid.
</ParamField>

<Callout kind="info" collapsed="false">
  Both OrderIds and DefualtDate must be provided for proper execution.
</Callout>

## Simple Explanation

The macro reads the dispatch date from XML, validates it, and updates the order. If the date is missing or invalid, it applies a default date to ensure the order remains processable.

## Step-by-Step Flow

<Steps>
  <Step title="Start Processing Orders" icon="play-circle" title-type="p">
    Take OrderIds and process each order individually.
  </Step>

  <Step title="Fetch Order & XML Data" icon="download" title-type="p">
    Retrieve order details and associated XML data.
  </Step>

  <Step title="Check Order Source" icon="filter" title-type="p">
    Process only Magento orders and skip others.
  </Step>

  <Step title="Read Dispatch Date from XML" icon="search" title-type="p">
    Extract value from the custom\_dispatch\_date field.
  </Step>

  <Step title="Validate Date" icon="check-circle" title-type="p">
    If valid → use it.\
    If invalid → log error.

  <Step title="Handle Missing Date" icon="alert-circle" title-type="p">
    If date is missing or empty → apply Default Date.
  </Step>

  <Step title="Update Order" icon="edit" title-type="p">
    Set Despatch By Date and save changes.
  </Step>

  <Step title="Track Updated Orders" icon="list" title-type="p">
    Store processed order IDs for tracking.
  </Step>

  <Step title="Assign Identifier" icon="tag" title-type="p">
    Assign tag "Despatch By Date" and create if not exists.
  </Step>

  <Step title="Logging" icon="file-text" title-type="p">
    Log errors, successful updates, and completion status.
  </Step>
</Steps>
