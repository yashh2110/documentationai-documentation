## Overview

The **RIS-SC-2246 – Item/Order-Level Picking Report** offers granular visibility into warehouse picking operations by tracking each order and item, identifying the responsible user, and measuring performance metrics.

<Callout kind="tip" collapsed="false">
  Use shorter time ranges for more precise analysis during audits or investigations.
</Callout>

## Purpose

This report:

- Tracks picking activity at item and order level

- Identifies who picked each item

- Measures time taken and accuracy

- Supports audits and performance analysis

👉 In short:\
Track items → assign user → measure accuracy & time → analyze performance.

## When It Runs

Typically executed:

- During audits and investigations

- For checking picking errors

- Staff performance reviews

- Daily operations analysis

- Identifying process delays

- Manually as needed

## Data Used

- Pickwave start and end time

- Orders within each pickwave

- Items planned vs items picked

- User (staff) performing the picking

The report tracks each order and item, identifies the responsible user, and measures time and accuracy to provide detailed performance insights.
