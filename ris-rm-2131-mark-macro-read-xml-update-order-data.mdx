## Overview

The **RIS-RM-2131 – Mark Macro** ensures that order data aligns with XML input, updates pricing and totals, flags special customers, and logs all previous values for auditing purposes.

<Callout kind="tip" collapsed="false">
  In simple terms:\
  Use XML as the source of truth to correct orders, flag customers, and maintain an audit trail.
</Callout>

## Purpose

This macro:

- Reads order data from XML

- Updates order items, prices, and totals

- Flags special customers based on CustomerGroupId

- Stores old values for auditing and tracking

- Adds notes for each processed order

---

## When It Runs

Typically executed:

- Automatically or manually during order validation

- After order import (Magento/Amazon XML sync)

- During data correction or reconciliation processes

- When customer group-based processing is required

- To fix mismatched order totals

## Simple Explanation

The macro reads XML for orders, updates item prices, tax, and totals, flags customers in specific groups, and stores previous values in extended properties for auditing.

---

## Step-by-Step Process

<Steps>
  <Step title="Fetch Orders" icon="inbox" title-type="p">
    Loop through provided OrderIds using Api.Orders.GetOrderById.
  </Step>

  <Step title="Load XML Data" icon="file-code" title-type="p">
    Retrieve XML using Api.Orders.GetOrderXml and parse item and pricing details.
  </Step>

  <Step title="Extract XML Values" icon="list" title-type="p">
    Get SKU, price, tax, row total, shipping, subtotal, tax, and total charge.
  </Step>

  <Step title="Identify Customer Group" icon="users" title-type="p">
    Check CustomerGroupId from XML to identify special customers.
  </Step>

  <Step title="Mark Special Customer" icon="flag" title-type="p">
    If CustomerGroupId = 4:

    - Add extended property flag using Api.Orders.SetExtendedProperties

    - Add order note using Api.Orders.SetOrderNotes
  </Step>

  <Step title="Store Old Values (Audit)" icon="archive" title-type="p">
    Save old item prices and totals (postage, subtotal, tax, total) in extended properties.
  </Step>

  <Step title="Update Order Items" icon="edit" title-type="p">
    Match SKU with XML, update price, cost, and tax using Api.Orders.UpdateOrderItem; recalculate if SKU not found.
  </Step>

  <Step title="Update Order Totals" icon="calculator" title-type="p">
    Replace totals using XML values via Api.Orders.SetOrderTotalsInfo.
  </Step>

  <Step title="Save Changes" icon="check-circle" title-type="p">
    Apply all updates to items, totals, extended properties, and notes.
  </Step>
</Steps>
