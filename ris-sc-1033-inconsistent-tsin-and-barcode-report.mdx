## Overview

The **RIS-SC-1033 – Inconsistent TSIN and Barcode Report** script helps analysts identify SKUs where barcode and TSIN values do not match.

<Callout kind="tip" collapsed="false">
  In simple terms:\
  Finds products where barcode and TSIN values are inconsistent.
</Callout>

## Purpose

This script:

- Compares SKU barcodes with their TSIN values  
- Identifies mismatched records  
- Ensures product identifier accuracy for marketplaces and internal systems  

---

## When It Runs

Used for data audits, catalog maintenance, and marketplace compliance.

**Typically runs:**

- Manually executed by analysts  
- During data audits  
- Before marketplace integrations  
- While validating product identifiers  
- During catalog maintenance  

---

## Parameters

<ParamField path="None" param-type="fixed" required="false" deprecated="false">
  No parameters; the script uses predefined validation logic on existing data.
</ParamField>

<Callout kind="info" collapsed="false">
  The script does not require manual input and checks all active SKUs.
</Callout>

---

## Simple Explanation

The script links SKUs with their extended TSIN properties, compares the TSIN with the barcode, and highlights only those records where the values differ.

---

## Step-by-Step Process

<Steps>
  <Step title="Join SKU with Extended Properties" icon="link" title-type="p">
    Map each product’s barcode with its TSIN value from extended properties.
  </Step>

  <Step title="Filter TSIN Property" icon="filter" title-type="p">
    Select only extended properties where the name is TSIN.
  </Step>

  <Step title="Compare Barcode and TSIN" icon="tag" title-type="p">
    Identify records where barcode and TSIN values do not match.
  </Step>

  <Step title="Exclude Invalid Records" icon="x-circle" title-type="p">
    Include only active and non-archived SKUs.
  </Step>
</Steps>
