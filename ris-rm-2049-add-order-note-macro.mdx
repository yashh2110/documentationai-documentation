## Overview

The **RIS-RM-2049 – Add Order Note Macro&#x20;**&#x6D;acro allows adding notes to selected orders.

It supports internal and external notes and can optionally mark notes as processing-related for workflow tracking.

<Callout kind="tip" collapsed="false">
  Ensure note content and visibility flags are correctly set before executing this macro.
</Callout>

## Purpose

This macro:

- Adds notes to orders

- Determines visibility (internal or external)

- Applies optional processing flag

- Preserves existing notes

👉 In short:\
Attach notes to orders efficiently with correct type and visibility.

## When It Runs

Used for order review, exception handling, or communication purposes

Typically runs:

- Manual execution

- During order review or processing

- For customer or warehouse communication

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">
  List of orders to update.
</ParamField>

<ParamField path="OrderNote" param-type="string" required="true" deprecated="false">
  Text content to be added as a note.
</ParamField>

<ParamField path="MarkExternal" param-type="boolean" required="false" deprecated="false">
  TRUE = external note (customer-visible), FALSE = internal note.
</ParamField>

<ParamField path="MarkProcessing" param-type="boolean" required="false" deprecated="false">
  TRUE = mark note as processing type, FALSE = regular note.
</ParamField>

## How It Works

<Steps>
  <Step title="Start Macro" icon="play-circle" title-type="p">
    Log macro start and prepare date filters (last 50 days).\
    ⚠️ Note: Some extra unused logic fetching specific orders does not affect execution.
  </Step>

  <Step title="Determine Note Type" icon="edit" title-type="p">
    If MarkProcessing = TRUE → set NoteTypeId = 0\
    Else → set NoteTypeId = null
  </Step>

  <Step title="Loop Through Orders" icon="list" title-type="p">
    Iterate through each OrderId and fetch order details.
  </Step>

  <Step title="Create Order Note" icon="file-text" title-type="p">
    If OrderNote is not null, create note with:

    - Text from OrderNote parameter

    - Visibility: TRUE → External, FALSE → Internal

    - Processing flag based on MarkProcessing

    - CreatedBy: "AddOrderNote Macro"

    - Timestamp: current date
  </Step>

  <Step title="Save Note" icon="save" title-type="p">
    Fetch existing notes using Api.Orders.GetOrderNotes()\
    Append new note and save using Api.Orders.SetOrderNotes()
  </Step>

  <Step title="Logging" icon="check-circle" title-type="p">
    Log macro start/end, order numbers processed, and note additions.
  </Step>
</Steps>

## Final Result

<Callout kind="success" collapsed="false">
  - Notes added to selected orders

  - Supports internal and external visibility

  - Optional processing flag applied

  - Existing notes remain intact
</Callout>
