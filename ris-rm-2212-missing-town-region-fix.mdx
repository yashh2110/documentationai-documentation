## Overview

The **RIS-RM-2212 – Missing Town & Region Fix** macro validates orders for missing address fields and fills them using a default region, ensuring smooth order processing.

<Callout kind="tip" collapsed="false">
  Ensure a valid default RegionName is provided before running this macro.
</Callout>

## Purpose

This macro:

- Checks for missing Town (City) and Region (State) values

- Fills missing fields using a default region

- Updates order addresses for processing

👉 In short:\
Detect missing Town/Region → fill with default → update order.

## When It Runs

Typically executed:

- After order import

- Before shipping label generation

- During order validation

- When address errors are detected

- Before sending orders to couriers

- Manually or via automation workflows

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">
  List of order IDs to process.
</ParamField>

<ParamField path="RegionName" param-type="string" required="true" deprecated="false">
  Default region to use for missing Town/Region fields.
</ParamField>

<Callout kind="info" collapsed="false">
  Both OrderIds and RegionName must be provided for the macro to function correctly.
</Callout>

## Simple Explanation

The macro checks each order for missing Town or Region fields and fills them with a default region, ensuring addresses are valid for shipping and processing.
