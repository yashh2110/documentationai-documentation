# 1. Overview

This system connects your business system with the ActiveAnts warehouse.

It automatically handles:
- Sending orders to the warehouse
- Receiving stock updates
- Updating processed orders
- Running scheduled background tasks

The main goal is to reduce manual work and ensure accurate, real-time operations.

---

# 2. Key Concepts

## 2.1 Warehouse Integration

The warehouse (ActiveAnts) is responsible for:
- Picking products
- Packing orders
- Shipping items

The system ensures your business and warehouse stay in sync.

---

## 2.2 Automation

Many processes run automatically in the background:
- Fetching new orders
- Updating stock
- Processing completed orders

---

# 3. Authentication

## Overview

Authentication is required before any communication with the warehouse.

---

## Token Based Access

### What happens

- System requests a secure token
- Token is used for all further communication
- Token expires and needs refresh

### Why it matters

- Ensures secure communication
- Prevents unauthorized access

---

## User Token Structure

### Includes

- User identity
- Access permission
- Expiry time

---

# 4. Order Management

## 4.1 Open Orders

### Purpose

Fetch orders that are not yet processed.

### Process

Step 1  
System checks for new orders  

Step 2  
Orders are collected  

Step 3  
Orders are prepared for warehouse  

### Business Value

- No order is missed  
- Orders are processed faster  

---

## 4.2 Order Processing

### Purpose

Send orders to warehouse and track progress.

### Process

Step 1  
Order is sent to warehouse  

Step 2  
Warehouse accepts order  

Step 3  
Warehouse processes order  

---

## 4.3 Processed Orders Update

### Purpose

Update system when warehouse completes orders.

### Process

Step 1  
Warehouse sends update  

Step 2  
System receives update  

Step 3  
Order status is changed to completed  

### Business Value

- Accurate tracking  
- Better customer updates  

---

## 4.4 Scheduled Order Fetching

### Purpose

Automatically check for new orders.

### Process

- Runs at fixed intervals  
- Fetches new open orders  
- Sends them for processing  

### Business Value

- Fully automated workflow  
- Reduces manual checks  

---
