## Getting started

Follow these steps to set up your workspace and prepare your first document.

<Steps>
  <Step title="Install dependencies" icon="download" title-type="p">
    Install the packages your documentation project needs.

    ```bash
    npm install
    ```

    After the install finishes, your terminal should return to the prompt without errors.
  </Step>

  <Step title="Start the local environment" icon="play-circle" title-type="p">
    Run the development server so you can preview changes as you work.

    ```bash
    npm run dev
    ```

    When the server starts, open the local address shown in your terminal.
  </Step>

  <Step title="Create your first page" icon="plus" title-type="p">
    Add a new document, write a short introduction, and save the page.

    Your first page should appear in the editor or file tree after it is created.
  </Step>

  <Step title="Review and publish" icon="check-circle" title-type="p">
    Preview the page, confirm the formatting, and publish it when the content is ready.

    A successful publish makes the page available to your team or readers.
  </Step>
</Steps>

<Callout kind="tip" collapsed="false">
  Start with one page and one clear owner. That keeps the first setup manageable and makes review faster.
</Callout>

## First steps

Use the first document to confirm that the editor, preview, and collaboration flow work the way you expect.

1. Write a title and a short summary.

2. Add one heading, one paragraph, and one list.

3. Preview the page and check the spacing.

4. Share the page with a teammate for feedback.

If the page renders correctly and your teammate can open it, your setup is ready for regular use.
