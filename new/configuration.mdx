## Setup File

You configure Yashwanth Documentation via a JSON file for flexibility. Locate `config.json` in the root directory. Edit values to match your environment.&#x20;

<CodeGroup show-lines="true" tabs={[]}>
  ```json
  {
    "port": 3000,
    "theme": "light"
  }
  ```

  ```json
  {
    "port": 3000,
    "theme": "dark",
    "auth": {
      "enabled": true,
      "provider": "oauth"
    }
  }
  ```
</CodeGroup>

<Callout kind="warning" collapsed="false">
  Backup your config before changes. Invalid JSON causes startup failures.
</Callout>

## Authentication

Enable secure access to protect your documents. Choose between local or external providers. Set up users and roles for granular control.

<Steps>
  <Step title="Enable Auth" icon="lock" title-type="p">
    Update the config to activate authentication.

    ```javascript
    // In config.js
    module.exports = {
      auth: {
        enabled: true
      }
    };
    ```
  </Step>

  <Step title="Add Users" icon="user" title-type="p">
    Use the admin panel to create accounts.

    ```bash
    node add-user.js --name admin --role owner
    ```
  </Step>

  <Step title="Test Login" icon="login" title-type="p">
    Verify access with credentials.
  </Step>
</Steps>

## Performance Tuning

Optimize for large document sets. Set cache limits and enable compression. Monitor usage to adjust settings dynamically.

```javascript
// Example optimization script
async function optimize() {
  await clearCache();
  console.log('Optimized');
```

## Security Best Practices

Implement measures to safeguard data. Use HTTPS in production. Regularly update dependencies to patch vulnerabilities.

| Setting       | Recommendation | Impact           |
| ------------- | -------------- | ---------------- |
| HTTPS         | Mandatory      | Encrypts traffic |
| Rate Limiting | Enable         | Prevents abuse   |
| Backups       | Daily          | Data recovery    |
