## Overview

The **RIS-RM-2016 – FolderAssignmentAndOrderItem** macro enhances order processing by adding additional items (from extended properties) and grouping similar orders into a folder.

It helps identify related orders and prepares them for merging or streamlined handling.

<Callout kind="tip" collapsed="false">
  Ensure item extended properties (AdditonalItem1 / AdditonalItem2) are properly configured before running this macro.
</Callout>

## Purpose

This macro:

- Reads item extended properties  
- Adds additional items to orders  
- Matches orders based on customer details  
- Assigns matching orders to a folder  

👉 In short:  
Add extra items and group similar orders for merge preparation.

## When It Runs

Used for order grouping and enrichment

Typically runs:

- Manually triggered (on selected orders)  
- During order processing workflows  
- For merge preparation and consolidation  

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">
  List of order IDs to process.
</ParamField>

<Callout kind="info" collapsed="false">
  Note:  
  Folder name is fixed as **"Possible Merge Orders"** and will be created automatically if it does not exist.
</Callout>

## How It Works

<Steps>
  <Step title="Fetch Open Orders" icon="download" title-type="p">
    Retrieve all open orders for comparison.
  </Step>

  <Step title="Process Selected Orders" icon="list" title-type="p">
    Loop through each OrderId and retrieve full order details.
  </Step>

  <Step title="Read Extended Properties" icon="settings" title-type="p">
    Check item-level properties such as AdditonalItem1 and AdditonalItem2.
  </Step>

  <Step title="Add Additional Items" icon="plus-circle" title-type="p">
    Find stock items using SKU and add them to the order (Quantity = 1).
  </Step>

  <Step title="Match Orders" icon="search" title-type="p">
    Compare orders using:
    - Address (Address1–3, Town, PostCode, Country)  
    - Full Name  
  </Step>

  <Step title="Group Matching Orders" icon="layers" title-type="p">
    Collect matching order IDs into a group.
  </Step>

  <Step title="Assign Folder" icon="folder" title-type="p">
    Assign orders to folder: "Possible Merge Orders"  
    (Auto-created if not present)
  </Step>

  <Step title="Log Results" icon="file-text" title-type="p">
    Record execution details including added items and grouping results.
  </Step>
</Steps>

## Final Result

<Callout kind="success" collapsed="false">
  - Additional items added to orders  
  - Similar orders identified successfully  
  - Orders grouped into "Possible Merge Orders" folder  
  - Execution logs available for tracking  
</Callout>

## Usefulness

This macro is highly beneficial for:

- Automating additional item or bundle logic  
- Identifying duplicate or mergeable orders  
- Improving warehouse and fulfilment efficiency  
- Reducing manual order review efforts  
- Supporting order consolidation workflows  

## Important Notes

<Callout kind="warning" collapsed="false">
  - Works only if extended properties (AdditonalItem1/2) exist  
  - Address matching is strict (all fields must match)  
  - May add duplicate items if executed multiple times  
  - Additional items are always added with quantity = 1  
  - Folder is auto-created if not present  
</Callout>
