## Overview

The **RIS-SC-2244 – Comparison Report (User vs User / Pickwave vs Pickwave)** enables side-by-side comparison of performance between two users or two pickwaves to identify efficiency, speed, and output differences.

<Callout kind="tip" collapsed="false">
  Use consistent date ranges and similar workloads for accurate and fair comparisons.
</Callout>

## Purpose

This report:

- Compares two users or two pickwaves

- Measures performance metrics side-by-side

- Highlights differences in speed, output, and efficiency

- Supports decision-making and performance evaluation

👉 In short:\
Compare → analyze → find difference → decide better performer.

## When It Runs

Typically executed:

- During performance reviews

- When comparing staff members

- When analyzing pickwave efficiency

- For improvement tracking

- For operational decision-making

- Manually as needed

## Parameters

<ParamField path="WaveA" param-type="number" required="false" deprecated="false">
  First pickwave ID for comparison.
</ParamField>

<ParamField path="WaveB" param-type="number" required="false" deprecated="false">
  Second pickwave ID for comparison.
</ParamField>

<ParamField path="FromDate" param-type="DateTime" required="false" deprecated="false">
  Start date for user comparison.
</ParamField>

<ParamField path="ToDate" param-type="DateTime" required="false" deprecated="false">
  End date for user comparison.
</ParamField>

<ParamField path="UserA" param-type="string" required="false" deprecated="false">
  First user for comparison.
</ParamField>

<ParamField path="UserB" param-type="string" required="false" deprecated="false">
  Second user for comparison.
</ParamField>

<Callout kind="info" collapsed="false">
  Provide either WaveA & WaveB for pickwave comparison OR UserA & UserB with date range for user comparison.
</Callout>

## Data Used

- Pickwave details (start time, end time)

- Orders within each pickwave

- Items picked

- User (staff) information

## Simple Explanation

The report compares two entities (users or pickwaves), analyzes their performance metrics, and displays the results side-by-side for easy evaluation.
