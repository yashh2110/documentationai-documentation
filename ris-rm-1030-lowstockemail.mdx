## Overview

The **RIS-RM-1030 – LowStockEmail** macro monitors stock levels in real time during order processing and sends email alerts when items reach zero stock.

It ensures only warehouse-managed items are evaluated by excluding dropship items using SQL-based detection.

<Callout kind="tip" collapsed="false">
  Ensure SMTP configuration and dropship detection logic are correctly set before running this macro.
</Callout>

## Purpose

This macro:

- Monitors stock levels during order processing  
- Detects when stock becomes zero  
- Excludes dropship items from checks  
- Sends email alerts automatically  

👉 In short:  
Detect stock-out events and notify instantly.

## When It Runs

Used for inventory monitoring and alerting

Typically runs:

- During order processing  
- Manual execution  
- During order import workflows

## How It Works

<Steps>
  <Step title="Process Orders" icon="list" title-type="p">
    Loop through each order provided in OrderIds.
  </Step>

  <Step title="Read Order Items" icon="box" title-type="p">
    Extract SKU, quantity, and current stock level for each item.
  </Step>

  <Step title="Detect Dropship Items" icon="search" title-type="p">
    Execute SQL query to identify dropship supplier items and skip them.
  </Step>

  <Step title="Calculate Stock Levels" icon="calculator" title-type="p">
    Determine:
    - Stock before order  
    - Stock after order  
  </Step>

  <Step title="Check Out-of-Stock Condition" icon="alert-triangle" title-type="p">
    Identify items where:
    Stock before > 0 AND stock after ≤ 0
  </Step>

  <Step title="Prepare Email Content" icon="edit" title-type="p">
    Create alert email with SKU and stock details.
  </Step>

  <Step title="Send Email Alerts" icon="send" title-type="p">
    Send notification to all configured recipients.
  </Step>

  <Step title="Log Execution" icon="file-text" title-type="p">
    Record success, failures, and processing details.
  </Step>
</Steps>

## Important Notes

<Callout kind="warning" collapsed="false">
  - Depends on SQL query for dropship detection  

  - Requires correct SMTP configuration  

  - No retry mechanism for failed emails  

  - Triggers only when stock reaches zero  

  - Duplicate recipients may receive multiple alerts  

  - Sensitive credentials are used in configuration  
</Callout>
