## Overview

The **RIS-CS-2265 – Process Order Script** generates a detailed package summary report by combining order data with shipping package information.

It intelligently handles missing data using fallback logic to ensure complete and reliable output.

<Callout kind="tip" collapsed="false">
  Uses deduplicated package records and fallback logic to ensure accurate package count and weight.
</Callout>

---

## Purpose

This report:

- Provides **order-level package summary**

- Calculates **package count and total weight**

- Extracts **shipping and tracking details**

- Handles **missing package data using fallback logic**

👉 In short:\
Get accurate package and shipping summary per order.

---

Executed on-demand (SQL report)

## How It Works

<Steps>
  <Step title="Fetch Base Order Data" icon="database" title-type="p">
    Retrieves:

    - Order ID

    - Channel reference

    - Order date

    - Source and SubSource

    - Postal service

    - Tracking number

    - Total value

    - Number of SKUs
  </Step>

  <Step title="Deduplicate Package Records" icon="filter" title-type="p">
    Removes duplicate package entries using:

    - OrderItem

    - Shipping

    - Package tables
  </Step>

  <Step title="Build Package Summary" icon="package" title-type="p">
    Creates readable summary:
    Package 1: 2kg; Package 2: 1.5kg

    Uses XML aggregation and row numbering.
  </Step>

  <Step title="Calculate Package Count" icon="hash" title-type="p">
    Counts distinct packages per order.
  </Step>

  <Step title="Calculate Total Weight" icon="bar-chart" title-type="p">
    Sums all package weights per order.
  </Step>

  <Step title="Apply Fallback Logic" icon="refresh-cw" title-type="p">
    If no package data exists:

    - Use OrderPackaging table

    - Default to:
      Package 1: 0kg
  </Step>

  <Step title="Finalize Output" icon="list" title-type="p">
    Combines:

    - Order data

    - Package summary

    - Package count

    - Total weight
  </Step>

  <Step title="Sort Results" icon="arrow-down" title-type="p">
    Orders sorted by latest order date.
  </Step>
</Steps>

## Important Notes

<Callout kind="warning" collapsed="false">
  - Deduplication is critical to avoid incorrect package counts

  - XML aggregation may impact performance on large datasets

  - Fallback logic ensures data completeness but may show default values

  - Date filter uses inclusive end date logic via DATEADD

  - Weight formatting is rounded for readability
</Callout>
