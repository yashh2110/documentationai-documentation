## Overview

The **RIS-RM-2252 – Last Name Update if Blank in Open Order** macro ensures customer name completeness by detecting missing last names and assigning a default value.

<Callout kind="tip" collapsed="false">
  This macro is essential before shipping label generation to avoid courier-related issues.
</Callout>

## Purpose

This macro:

- Detects missing last names in customer data

- Assigns a default last name

- Updates full name in order address

- Ensures clean and standardized data

👉 In short:\
Check name → add last name → update order → ensure completeness.

## When It Runs

Typically executed:

- After order import from sales channels

- When customer data is incomplete

- Before shipping label generation

- For courier compliance

- During order processing workflows

- Manually or via automation

## Parameters

<ParamField path="OrderIds" param-type="GUID[]" required="true" deprecated="false">
  List of orders to process.
</ParamField>

<ParamField path="SetLastName" param-type="string" required="true" deprecated="false">
  Default last name to assign when missing.
</ParamField>

<Callout kind="info" collapsed="false">
  Example: "John" → "John Customer"
</Callout>

## Simple Explanation

The macro checks if a customer's name contains only a first name. If so, it appends a default last name and updates the order.
