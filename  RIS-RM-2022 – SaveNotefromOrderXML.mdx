## Overview

The **RIS-RM-2022 – SaveNotefromOrderXML** macro extracts note information directly from an order’s XML data and stores it as an order note in Linnworks.

It ensures that important information coming from external systems is captured and made visible within the order.

<Callout kind="tip" collapsed="false">
  Ensure the XML structure contains the correct Note tag before running this macro.
</Callout>

## Purpose

This macro:

- Reads order XML data  
- Extracts note content  
- Saves note as an order note  
- Makes note externally visible  

👉 In short:  
Extract and save notes from XML into the order automatically.

## When It Runs

Used for data enrichment and integration handling

Typically runs:

- Manual execution (on selected orders)  
- Triggered via Rules Engine  
- When external systems send notes via XML  

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">
  List of order IDs to process.
</ParamField>

<Callout kind="info" collapsed="false">
  Note:  
  - Works only on provided OrderIds  
  - No additional configuration required  
</Callout>

## How It Works

<Steps>
  <Step title="Process Orders" icon="list" title-type="p">
    Loop through each OrderId provided.
  </Step>

  <Step title="Fetch Order XML" icon="download" title-type="p">
    Retrieve XML data using GetOrderXml API.
  </Step>

  <Step title="Parse XML" icon="code" title-type="p">
    Convert XML string into structured format using XElement.
  </Step>

  <Step title="Check Note Element" icon="search" title-type="p">
    Look for the Note tag inside the XML.
  </Step>

  <Step title="Extract Note Value" icon="file-text" title-type="p">
    Read the content inside the Note element.
  </Step>

  <Step title="Validate Note" icon="check-circle" title-type="p">
    Ensure the extracted note is not empty.
  </Step>

  <Step title="Save Note to Order" icon="edit" title-type="p">
    Create a new order note:
    - Note text = extracted value  
    - Internal = false (external note)  
    - CreatedBy = "Add Note From Order XML"  
  </Step>

  <Step title="Log Execution" icon="file-text" title-type="p">
    Track processed orders and any errors.
  </Step>
</Steps>

## Important Notes

<Callout kind="warning" collapsed="false">
  - Works only if Note tag exists in XML  
  - Existing notes may be overwritten (not appended)  
  - Notes are always saved as external  
  - No duplicate check (same note can be added multiple times)  
  - XML structure must be valid  
</Callout>
