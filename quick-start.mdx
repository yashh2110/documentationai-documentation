## Prerequisites

<Callout kind="info" title="Before You Begin">
Ensure you have:
- A valid email address for registration
- Business details ready (company name, industry)
- Access to your Linnworks or Odoo account credentials if integrating
</Callout>

Rishvi provides services for Linnworks automation, Odoo ERP, digital marketing, and custom software. Follow these steps to register, request a demo, and start your first integration.

## Step 1: Create Your Account

<Steps>
  <Step title="Register" icon="user-plus">
    Visit `https://rishvi.co.uk` and click **Sign Up**.

    Fill in your details:

    | Field       | Description                  |
    |-------------|------------------------------|
    | Email       | Your business email          |
    | Company     | Your company name            |
    | Password    | Strong password (`>12 chars`) |

    Submit the form to receive a verification email.
  </Step>

  <Step title="Verify Email" icon="mail">
    Check your inbox and click the verification link.
  </Step>

  <Step title="Login" icon="log-in">
````bash
# Direct login URL
https://rishvi.co.uk/login
````

    Enter your credentials to access the dashboard.
  </Step>
</Steps>

## Initial Integration Setup

Connect your first service using the dashboard tools.

<CodeGroup tabs="Linnworks,Odoo">
```javascript
// Linnworks API setup
const LINNWORKS_API_KEY = "YOUR_LINNWORKS_KEY";
const response = await fetch("https://api.example.com/linnworks/inventory", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${LINNWORKS_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ channel: "amazon" })
});
```

```javascript
// Odoo integration example
const ODOO_URL = "https://your-odoo.com";
const API_KEY = "YOUR_ODOO_KEY";

const data = await fetch(`${ODOO_URL}/xmlrpc/2/object`, {
  method: "POST",
  body: JSON.stringify({
    service: "object",
    method: "execute_kw",
    args: ["database", API_KEY, "res.partner", "search", [[]]]
  })
});
```
</CodeGroup>

<ParamField path="apikey" param-type="string" required="true">
Your Rishvi API key from dashboard settings.
</ParamField>

<ParamField header="Authorization" param-type="string" required="true">
Format: `Bearer YOUR_API_KEY`
</ParamField>
