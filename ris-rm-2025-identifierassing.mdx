## Overview

The **RIS-RM-2025 – IdentifierAssing** macro automates order tagging by evaluating shipping and payment method values directly from order XML.

It ensures that orders meeting specific conditions are identified and tagged with a predefined identifier for easier tracking and workflow automation.

<Callout kind="tip" collapsed="false">
  Ensure shipping and payment method values are correctly defined and match XML data before running this macro.
</Callout>

## Purpose

This macro:

- Reads shipping method from XML

- Reads payment method from XML

- Matches against configured values

- Assigns identifier to matching orders

👉 In short:\
Tag orders automatically based on shipping or payment method.

## When It Runs

Used for order classification and tagging

Typically runs:

- Manual execution (on selected orders)

- Triggered via Rules Engine

- After order import

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">
  List of order IDs to process.
</ParamField>

<ParamField path="IdentifierName" param-type="string" required="true" deprecated="false">
  Identifier to assign to matching orders.
</ParamField>

<ParamField path="ShippingMethod" param-type="string" required="false" deprecated="false">
  Comma-separated list of shipping methods to match.
</ParamField>

<ParamField path="PaymentMethod" param-type="string" required="false" deprecated="false">
  Comma-separated list of payment methods to match.
</ParamField>

<Callout kind="info" collapsed="false">
  Matching Logic:

  - Shipping method match OR

  - Payment method match

  If either condition is satisfied → identifier is assigned.
</Callout>

## How It Works

<Steps>
  <Step title="Prepare Input Lists" icon="settings" title-type="p">
    Split ShippingMethod and PaymentMethod into structured lists.
  </Step>

  <Step title="Process Orders" icon="list" title-type="p">
    Loop through each OrderId and process orders individually.
  </Step>

  <Step title="Fetch Order XML" icon="download" title-type="p">
    Retrieve XML data using GetOrderXml API.
  </Step>

  <Step title="Extract Values" icon="search" title-type="p">
    Read shipping method and payment method from XML.
  </Step>

  <Step title="Match Conditions" icon="check-circle" title-type="p">
    Check if:

    - Shipping method matches configured list\
      OR

    - Payment method matches configured list
  </Step>

  <Step title="Collect Matching Orders" icon="filter" title-type="p">
    Add matching orders to a processing list.
  </Step>

  <Step title="Assign Identifier" icon="tag" title-type="p">
    - Check if identifier exists

    - Create identifier if missing

    - Assign it to all matching orders
  </Step>

  <Step title="Log Execution" icon="file-text" title-type="p">
    Record processed orders and any issues.
  </Step>
</Steps>
