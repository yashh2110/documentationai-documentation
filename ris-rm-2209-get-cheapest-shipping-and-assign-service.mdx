## Overview

The **RIS-RM-2209 – Get Cheapest Shipping and Assign Service** macro selects the optimal shipping method for each order by retrieving live quotes from available couriers and applying business logic to assign the best option.

<Callout kind="tip" collapsed="false">
  Ensure all courier integrations are configured and active before running this macro.
</Callout>

## Purpose

This macro:

- Retrieves live shipping quotes

- Compares available courier services

- Assigns the most cost-effective or suitable shipping method

- Logs changes for audit purposes

👉 In short:\
Get cheapest shipping quote → select optimal service → assign to order → log changes.

## When It Runs

Used for shipping cost optimization and courier selection automation

Typically runs:

- During order processing

- Before shipping label generation

- After order import

- Manually triggered or via automation workflows

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">

</ParamField>

<Callout kind="info" collapsed="false">

## Simple Explanation

The macro checks all shipping options for an order, selects the cheapest or most suitable based on predefined rules, assigns it, and records the updates for auditing.
