## Overview

The **RIS-SC-2258 – Printing Report** retrieves printwear-related orders using specific identifiers, formats invoice numbers, and extracts item customization details and external notes.

It ensures only relevant orders are included for printing workflows while excluding already processed ones.

<Callout kind="tip" collapsed="false">
  Uses identifier-based filtering and XML string aggregation to extract customization and notes efficiently.
</Callout>

---

## Purpose

This report:

- Filters **printwear-specific orders**

- Formats **invoice reference with prefix (IE / COM)**

- Extracts **item customization details**

- Includes **external order notes only**

- Excludes **already exported orders**

👉 In short:\
Get clean, print-ready order data with customization.

---

Executed on-demand (SQL report)

Typically used:

## How It Works

<Steps>
  <Step title="Fetch Open Orders" icon="database" title-type="p">
    Retrieves open orders and their items.
  </Step>

  <Step title="Filter Parent Items Only" icon="filter" title-type="p">
    Uses:
    fkCompositeParentRowId IS NULL\
    👉 Prevents duplicate rows from bundle components.
  </Step>

  <Step title="Apply Identifier Filter" icon="tag" title-type="p">
    Includes orders with:

    - Required Identifier

    Excludes orders with:

    - Exported Identifier
  </Step>

  <Step title="Apply Date Filters" icon="calendar" title-type="p">
    Filters orders between:

    - FromDate

    - ToDate
  </Step>

  <Step title="Filter by Sales Channel" icon="globe" title-type="p">
    Includes only:

    - Source (.COM) Website

    - Source (.IE) Website
  </Step>

  <Step title="Format Invoice Number" icon="hash" title-type="p">
    Creates prefixed invoice:

    - IE → Irish website

    - COM → Global website

    Example:
    \#IE96462
  </Step>

  <Step title="Extract Customisation Data" icon="settings" title-type="p">
    Uses XML aggregation to combine:

    - Property

    - Value

    Format:
    Size: M | Color: Red
  </Step>

  <Step title="Extract External Notes" icon="file-text" title-type="p">
    Retrieves only:

    - Non-empty notes

    - External notes (Internal = 0)
  </Step>

  <Step title="Sort Output" icon="list" title-type="p">
    Orders sorted by:

    - Order ID

    - SKU
  </Step>
</Steps>

## Important Notes

<Callout kind="warning" collapsed="false">
  - Only orders with required identifier are included

  - Orders with export identifier are excluded

  - SubSource filter is strict (COM / IE only)

  - XML aggregation may impact performance on large datasets

  - Composite child items are excluded

  - ExternalReference must exist for proper invoice formatting
</Callout>
