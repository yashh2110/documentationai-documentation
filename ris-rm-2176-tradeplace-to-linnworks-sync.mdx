## Overview

The **RIS-RM-2176 – Tradeplace To Linnworks Sync&#x20;**&#x6D;acro fetches product data from Linnworks based on supplier and extended properties, sends availability requests to TradePlace, retrieves confirmed stock quantities, generates a CSV file, and uploads it to an FTP server.

<Callout kind="tip" collapsed="false">
  Automates supplier stock confirmation and FTP export for seamless integration.
</Callout>

## Purpose

This macro:

- Fetches product data from Linnworks by supplier name

- Sends XML availability requests to TradePlace API

- Receives confirmed quantities

- Generates CSV from updated DataTable

- Uploads the CSV to an FTP server

👉 In short:\
Syncs product availability from Linnworks → TradePlace → FTP automatically.

## When It Runs

Typically used:

- Scheduled or manual execution

- Before order processing

- During stock validation workflows

- On daily/hourly automation

- When checking supplier availability

- Before sending orders to suppliers

## Simple Explanation

This macro retrieves products from Linnworks, sends them to TradePlace for stock confirmation, updates the DataTable with confirmed quantities, generates a CSV file, and uploads it to FTP automatically.

## Step-by-Step Process

<Steps>
  <Step title="Initialize Macro" icon="play-circle" title-type="p">
    Log start and initialize variables.
  </Step>

  <Step title="Fetch Linnworks Data" icon="database" title-type="p">
    Execute custom script query filtering by supplierName and store results in a DataTable.
  </Step>

  <Step title="Build TradePlace XML Request" icon="file-code" title-type="p">
    Construct XML request with item EANs, requested quantities, and customer info.
  </Step>

  <Step title="Send XML Request" icon="send" title-type="p">
    Authenticate and POST XML to TradePlace API endpoint.
  </Step>

  <Step title="Parse Response XML" icon="file-text" title-type="p">
    Extract confirmed quantities and update DataTable.
  </Step>

  <Step title="Generate CSV" icon="file-csv" title-type="p">
    Convert DataTable to CSV and save locally.
  </Step>

  <Step title="Upload CSV to FTP" icon="upload" title-type="p">
    Use FTP proxy to upload CSV to configured FTP server.
  </Step>

  <Step title="Logging & Error Handling" icon="alert-triangle" title-type="p">
    Log errors, skipped items, and macro completion.
  </Step>
</Steps>
