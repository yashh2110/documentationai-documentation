## Overview

The **RIS-RM-2042 – Add Last Name** macro standardizes customer names by ensuring every order has both a first and last name.  

If only a single name is present, it automatically appends a predefined default last name.

<Callout kind="tip" collapsed="false">
  Ensure the default last name is correctly configured before executing this macro.
</Callout>

## Purpose

This macro:

- Checks customer names in orders  
- Adds a default last name if missing  
- Updates the order automatically  

👉 In short:  
Ensure full names are complete for all orders.

## When It Runs

Used for order processing and data cleanup  

Typically runs:

- During order processing  
- Before shipping label generation  
- Before courier integration  
- Manual execution when needed  

## Parameters

<ParamField path="OrderIds" param-type="string" required="true" deprecated="false">
  List of orders to process.
</ParamField>

<ParamField path="SetLastName" param-type="string" required="true" deprecated="false">
  Default last name to append when missing.
</ParamField>

## How It Works

<Steps>
  <Step title="Start Macro" icon="play-circle" title-type="p">
    Loop through all provided Order IDs and fetch each order.
  </Step>

  <Step title="Read Customer Name" icon="user" title-type="p">
    Read: `order.CustomerInfo.Address.FullName`.
  </Step>

  <Step title="Split Name" icon="split" title-type="p">
    Split the name using space " " and store parts in an array.
  </Step>

  <Step title="Check if Last Name is Missing" icon="alert-circle" title-type="p">
    If array contains only one word → last name is missing.
  </Step>

  <Step title="Add Default Last Name" icon="edit" title-type="p">
    Update name to: `FirstName + " " + SetLastName`.  
    Mark order as modified.
  </Step>

  <Step title="Update Order" icon="sync" title-type="p">
    Save updated customer details back to the order.
  </Step>

  <Step title="Logging" icon="check-circle" title-type="p">
    Log:
    - Order number  
    - Original name  
    - Updated name (if changed)  
    - No change message (if already valid)  
    - Errors
  </Step>
</Steps>

## Important Notes

<Callout kind="warning" collapsed="false">
  - Does not modify names that already contain multiple words  
  - Default last name must be properly configured  
  - Works only on FullName field (not separate fields)  
  - Assumes space-separated naming format  
  - Lightweight and fast execution
</Callout>
